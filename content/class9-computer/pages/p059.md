EXAMPLE 2: Now, let us construct a more complex Boolean function with three inputs, A, B, and C:

F (A, B, C) = A · B + A̅ · C

This function uses AND, OR and NOT at the same time. The truth table for this function is as follows:

**Explanation:**

• The parameters A, B, and C are included in the following example as the input columns.  
• The results of AND operation between two variable A and B are presented in the column A · B.  
• The column A̅ standing for the NOT operation of A.  
• Every value in the column A̅ · C displays the result of AND operation between the values in the Fifth column and the third column.  
• The final column F (A, B, C) shows the output of the Boolean function (A · B) + (A̅ · C)
