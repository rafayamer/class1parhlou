## 2.1.3 Octal System

Octal is a positional numeral system with base eight, which implies that a digit to be used ranges from 0 to 7. The last digit is a single digit power of 8 while the other digits are the coefficients. In the decimal system, the place values starting from the 8⁰, 8¹, 8² and so on. For example, the octal number 157₈ means, 1 x 8² + 5 x 8¹ + 7 x 8⁰ = 64 + 40 + 7 = 111₁₀.

Each octal digit represents three binary digits (bits) because the octal system is base-8, and the binary system is base-2. This relationship arises from the fact that 8 is a power of 2 (8 = 2³). So, each octal digit can be precisely represented by three binary digits (bits). This means that any value from 0 to 7 in octal can be converted into a 3-bit binary number.
