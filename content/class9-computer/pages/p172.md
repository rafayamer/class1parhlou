## 8.7.1 Basic Syntax and Examples

Here is a simple example to display an alert message using JavaScript:

```html
<!DOCTYPE html>
<html>
    <head>
    <title>JavaScript Example</title>
    </head>
<body>
    <h1>Welcome to JavaScript</h1>
    <script>
    alert("Hello, 9th Class Students!");
    </script>
</body>
</html>
```
